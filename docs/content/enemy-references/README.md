## Reference use rule

Each new family review should compare against the saved image only for abstract properties:

- overall mass ratio
- one dominant silhouette hook
- appendage size/count
- face-to-body ratio
- softness / toy-like simplification
- secondary-motion opportunity

Do not use reference screenshots as textures, tracing bases, or production UI imagery.

## Production acceptance

Reference has served its purpose only if the resulting enemy remains clearly original while preserving the intended cute principle.

At 128px grayscale:

- each enemy in an Area is distinguishable
- face is not the dominant feature
- role is readable before color
- no reference-specific costume/detail is required for recognition

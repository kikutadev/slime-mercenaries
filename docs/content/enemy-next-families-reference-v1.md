# Enemy Next Families Visual Reference — Leaf / Flower / Forest Critter

Status: Active production reference
Date: 2026-09-18

## 1. Purpose

Mushroom V2で確立した「小さい顔・大きい単純形状・シルエット先行」を、次の3 enemy familyへ展開する。

対象:

- Leaf family — 葉っぱ系
- Flower family — 花系
- Forest Critter family — 小動物系

これはIPのキャラクターを模写する資料ではない。各外部例から、**可愛さを成立させる比率・単純化・素材・一つの強い輪郭特徴**だけを抽出する。

Production modelは必ず独自シルエットへ再設計する。

---

## 2. Shared cute-character rules

Mushroom V2の失敗修正をそのまま次familyにも適用する。

1. **目を主役にしない。**
   - 通常敵の目は全高の6–10%を目標。
   - hard capは12%。
   - 巨大な黒目・巨大な白ハイライトは禁止。

2. **128px grayscale thumbnailで識別できる。**
   - 色差だけで別種にしない。
   - 同family内でも輪郭比率を変える。

3. **一体につき大きな特徴は一つ。**
   - 葉の形
   - 花弁 / 綿毛
   - 尾 / 柔らかい針
   のような大形状を先に作り、小物を足しすぎない。

4. **plush / toy massを優先する。**
   - 尖りを丸める。
   - realistic anatomy / botanical detailを減らす。
   - 小画面では質感よりmassが先に読めるようにする。

5. **顔は低く、小さく、静かに置く。**
   - Mushroom V2と同様、顔が輪郭を支配しない。

6. **通常敵は味方スライムより装飾密度を低くする。**
   - 主役はfriendly slime。

## 3. Leaf family references

### External references reviewed

#### Jellycat — Silly Seedling Serene
https://jellycat.com/silly-seedling-serene/

抽出する原則:

- 葉そのものが大きなキャラクター形状として成立する
- 顔を小さくしても十分に愛嬌が出る
- 植物を人型にしなくてもキャラクター化できる

#### Jellycat — Vivacious Vegetable Kale Leaf
https://jellycat.com/vivacious-vegetable-kale-leaf/

抽出する原則:

- 葉のruffle / foldがシルエット差として強い
- leaf edge detailを全面に増やさず、大きなうねりとして扱う
- soft stalk + broad leafの対比で植物らしさが出る

#### Jellycat — Amuseables Aloe Vera
https://jellycat.com/amuseables-aloe-vera-small/

抽出する原則:

- 複数の葉は少数の大きなbladeとして整理する
- 細い葉を大量に生やさない
- vertical silhouetteは遠目でも別familyとして読める

### Leaf family production shape language

Leaf familyはMushroomの「cap + body」を流用しない。

共通:

- matte / velvety green
- body centerは小さく、葉の大形状が輪郭を作る
- veinは1本の主脈 + 最大2本程度。細密葉脈は禁止
- rigid human arm / legは禁止
- 移動はflutter / skip / wind-sway

### Proposed production forms

#### A. ちびリーフ (`leafling`)

Silhouette:

- 1枚の丸いheart / teardrop leaf
- 下側に小さなbean core
- leafが全高の約65–75%
- 顔はleaf下部またはcore上部に低く配置

Hook:

> 1枚葉がぴょこぴょこ動く、小さく軽い敵。

Do not:

- 大きいanime eyes
- 人間の手足
- thin realistic stem

#### B. くるりリーフ (`whirl-leaf`)

Silhouette:

- 2枚の葉を少しずらしたpinwheel形
- leaflingより横方向へ広い
- 中心bodyは小さい

Hook:

> 2枚葉が風車のように回る、速いharasser。

Leaflingとの差は色ではなく、**single leaf vs two-leaf pinwheel**で出す。

### Leaf acceptance

- grayscaleで `leafling` と `whirl-leaf` が1秒以内に区別できる
- leaf edgeが細かすぎない
- idle時に植物としての柔らかい揺れがある
- move時に地面を足で歩いているように見えない

## 4. Flower family references

### External references reviewed

#### Jellycat — Fleury Sunflower
https://jellycat.com/fleury-sunflower/

抽出する原則:

- 中央の丸いmass + 少数の大きいpetalで花と即認識できる
- petalを細かく増やさなくても十分にflower identityが出る
- soft center / petal contrastがplush-likeで可愛い

#### Jellycat — Fleury Gerbera
https://jellycat.com/fleury-gerbera/

抽出する原則:

- petal crownそのものが強い輪郭になる
- 横に広い低い形でもflower identityが保てる
- radial symmetryは小画面で読みやすい

#### Jellycat — Fleury Daisy
https://jellycat.com/fleury-daisy/

抽出する原則:

- face center + floppy petalsという非常に単純な構成で成立する
- petalは柔らかく垂れる方がtoy-likeになる

#### Crochet Flower Buddy example
https://www.etsy.com/listing/4327618337/flower-buddy-plush-cute-crochet-flower

抽出する原則:

- rounded petal + tiny face + compact green lower mass
- 花弁の数を抑え、1枚ずつ大きくする方がキャラクターとして読みやすい

### Flower family production shape language

共通:

- flower headが主役
- stemは短く太く、realistic thin stemにしない
- petalsは4–8枚程度の大きなsoft lobes
- centerは大きいが、顔パーツは小さい
- idleはpetal breathing / droop
- attack時にpetal open/closeを使う

### Proposed production forms

#### A. つぼみん (`bud-bloom`)

Silhouette:

- 閉じた丸いbud
- 下部に2枚だけleaf skirt
- vertical pear / tulip-bud形

Hook:

> まだ咲いていない小さなつぼみが、縮んでからぽんっと突く。

Do not:

- humanoid flower fairy
- long realistic stem
- petal detailを刻みすぎる

#### B. ぽふぽふ花 (`puff-flower`)

Silhouette:

- 大きな丸いdandelion / pom-pom head
- bodyは非常に小さい
- bud-bloomより明確に横広 / round

Hook:

> 綿毛のような丸い頭から、小さな花粉をぽふっと飛ばすranged enemy。

Budとの差は **closed vertical bud vs round puff head** で出す。

### Flower acceptance

- flower headだけでfamilyを識別できる
- petal / puffの細部がノイズ化しない
- attack tellがpetal/budの形状変化で読める
- projectileが本体より派手になりすぎない

## 5. Forest Critter family references

### External references reviewed

#### Palm Pals — Hedgie Hedgehog
https://palmpals.com/products/33470-5in-hedgie-hedgehog

抽出する原則:

- palm-size / bean-like body
- spikeをrealisticな針ではなくsoft texture massとして扱う
- small paws / faceで十分にanimal identityが出る

#### Palm Pals — Flaps Flying Squirrel
https://palmpals.com/products/33853-flaps-flying-squirrel

抽出する原則:

- bodyより耳・tail/wing-like side silhouetteの方が種差に効く
- compact rounded bodyを維持しつつ一つの特徴を強くできる

#### Palm Pals — Gus Grey Squirrel
https://palmpals.com/products/33756-gus-grey-squirrel

抽出する原則:

- squirrelは大きなtail silhouetteだけで識別性が高い
- bodyは単純なround massでよい

#### Palm Pals — Chatty Mouse
https://palmpals.com/products/33773-chatty-mouse

抽出する原則:

- mouse identityは大きな丸耳 + 小さいnoseで出せる
- detailed anatomyは不要

#### Stylized 3D Hedgehog example
https://www.cgtrader.com/3d-models/animal/mammal/cute-stylized-hedgehog-adorable-3d-character-model

抽出する原則:

- 3Dでもbean body + simplified quill massで読みやすい
- individual spine detailを増やしすぎない

### Forest Critter production shape language

小動物系はplant enemyよりanimation負荷が高いので、最初からrealistic quadruped rigにはしない。

共通body grammar:

- low bean / pear body
- very short feet
- small muzzle or nose
- tiny bead eyes
- family identityは耳 / tail / soft-quill shellの大形状で出す
- fur shaderではなくmatte plush material

### Proposed production forms

#### A. まるハリ (`round-hedgehog`)

Silhouette:

- low bean body
- 背中を覆う1つのsoft-quill shell
- pointed individual spikesは禁止
- tiny snout

Hook:

> もこもこの針を丸めて、ころんと転がってぶつかる。

#### B. どんぐりリス (`acorn-squirrel`)

Silhouette:

- compact pear body
- bodyと同程度の大きなcrescent / cloud tail
- 小さい耳

Hook:

> 大きな尾でバランスを取りながら、どんぐりを投げる素早い敵。

Hedgehogとの差は **shell silhouette vs oversized tail silhouette** で出す。

### Critter acceptance

- realistic animal anatomyへ寄りすぎない
- tail / soft quillが一目で読める
- 4本足のwalk cycleを要求しない
- tiny hop / scamperで可愛さを保つ
- defeatがrealistic painに見えない

## 6. Cross-family silhouette board target

128px grayscale thumbnailで次の6体を並べ、色なしで全て区別できること。

```text
Leafling       = single broad leaf / compact
Whirl Leaf     = two-leaf pinwheel / wide
Bud Bloom      = closed vertical bud
Puff Flower    = round flower puff / radial
Round Hedgehog = low bean + shell
Acorn Squirrel = pear body + huge tail
```

Mushroomと比較した場合も、どの新familyもcap/stem silhouetteへ戻らない。

## 7. Face rules

Normal enemy:

- eye visible diameter/height target: character total heightの6–10%
- hard cap: 12%
- mouthは常時必須ではない
- cheekは必要な場合だけ、非常に小さく
- glossy giant ovalは禁止

Critterだけはnoseを持てるが、eye sizeを増やす理由にはしない。

Defeat expression:

- `×` eyeはnormal eye footprintの約1.0–1.25倍以内
- defeat時だけ巨大記号にしない
- body/petal/leaf/tail reactionの方を主役にする

## 8. Material references

Target:

- leaf: soft matte / slightly velvety
- flower: plush / felt-like, center and petals have mild roughness difference
- critter: matte plush, no realistic fur shader

Avoid:

- wet plastic
- metallic vegetation
- high-frequency fur
- strong subsurface that washes out face

Friendly slime remains glossier than normal enemies.

---

## 9. Motion reference principles

Cute motion priority:

1. anticipationが読める
2. releaseが短く気持ちよい
3. secondary partが遅れて付いてくる
4. recoveryでsoft settleする

Secondary motion by family:

- Leaf: leaf tip lag / flutter
- Flower: petal lag / bud compression / puff recoil
- Critter: tail follow-through / ear wobble / soft shell recoil

Every production enemy requires:

- Idle
- Move
- Attack
- Hit
- Defeat
- Signature projectile/VFX where applicable

Gameとgalleryで別アニメーションを作らない。

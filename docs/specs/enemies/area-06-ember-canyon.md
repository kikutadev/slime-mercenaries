# Area 6 — Ember Canyon

Status: Approved content specification; implementation may be pending
Date: 2026-09-19

## Identity

Fire / lavaを大量particleで表現しない。charcoal / stone mass + one controlled emissive elementで読む。

## Roster

### ひのこヤモリ

Role: fast melee. Silhouette: short round lizard + flame-tail tip.

- Idle: tail flame breathes, body mostly calm
- Move: short scurry, tail follows
- Attack: crouch → flame grows → fast dash → tail whips after body stops
- Hit: tail overshoot
- Defeat: flame shrinks to ember, body flops softly

### すみころ

Role: telegraphed bruiser. Silhouette: charcoal ball + 2–3 broad glowing cracks.

- Idle: almost still
- Move: short heavy roll
- Attack: cracks dark red → red → yellow → burst bump
- Hit: cracks briefly dim
- Defeat: glow cools, ball settles

### ぱちパチムシ

Role: ranged / timing pressure. Silhouette: compact beetle + one rounded charge shell.

- Idle: shell tiny pulse
- Move: hop/scuttle without realistic six-leg cycle
- Attack: shell shake #1 → shake #2 → short pause → compact spark release
- Hit: shell closes
- Defeat: charge fizzles with one harmless spark

### マグマガニ

Role: side-lane attacker. Silhouette: extremely wide body + two compact rounded claws.

- Idle: alternating claw weight
- Move: side-slide
- Attack: weight shifts one side → body snaps opposite direction → shoulder/claw bump
- Hit: one claw folds in
- Defeat: body lowers, claws rest inward

## Boss — 炉心ガメ

Silhouette: thick vertical turtle + central furnace shell.

Attack: furnace opens → core turns red/orange/white → body compresses → heavy jump/impact → 0.15s delayed fire ring。

Secondary: shell vent → short directional flame → recoil。

Defeat: furnace closes → glow fades → turtle sits down heavily。

## Stage structure

1. ひのこヤモリ
2. すみころ
3. ぱちパチムシ
4. マグマガニ + mixed pressure
5. 全4種 → 炉心ガメ

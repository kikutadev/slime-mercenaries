# Area 3 — Amber Mine

Status: Approved content specification; implementation may be pending
Date: 2026-09-19

## Identity

「硬い鉱石」ではなく、丸いbody + 一個の大きい結晶massで可愛さを作る。Faceted detailはcrystalだけ。body / limbはsoft rounded shape。

## Roster

### ころクリ — Crystal Beetle

Role: basic melee. Silhouette: low round bug + one oversized crystal on back.

- Idle: body breathe。crystalは0.08秒ほど遅れて揺れる
- Move: belly glide / tiny hop、crystal lag
- Attack: crouch → crystal leans forward → short tackle → crystal rebound
- Hit: body stops first, crystal continues wobble
- Defeat: half-roll, crystal stays intact, small × eyes

### つるはしモグ — Drill-Nose Mole

Role: mobile ambusher. Silhouette: squat mole + one short ore/drill-like nose。Toolは持たせない。

- Idle: tiny nose sniff
- Move: short dig / pop motion
- Attack: dive → moving ground bump → pop-up strike
- Hit: nose and cheeks compress
- Defeat: face-first soft bury

### きらコウモリ — Crystal Bat

Role: ranged / mobility. Silhouette: head/body mass dominant + small rounded wings + tiny crystal accent.

- Idle: wing-close hover
- Move: close → drop slightly → one flap → float
- Attack: wings close → body pulse → 1–2 ring shots
- Hit: wing folds asymmetrically
- Defeat: spiral down, soft landing

### ゴロゴーレム — Pebble Golem

Role: sturdy melee. Silhouette: three rounded rock masses floating tightly together.

- Idle: three masses drift slightly apart
- Move: lower rock rolls while upper masses lag
- Attack: all masses compress to center → release → tackle
- Hit: parts separate briefly, spring back
- Defeat: three parts settle into a harmless stone pile

## Boss — 琥珀ガメ

Silhouette: squat turtle + one giant amber shell.

Attack 1: head/feet retract → amber shell lights center-out → 0.18s hold → fast roll → large deceleration / shell wobble。

Attack 2: shell raises → amber glow gathers → short crystal pulse → recoil into shell。

Defeat: glow drains → one slow roll → lands sideways/upside-down without shell breakage。

## Stage structure

1. ころクリ
2. ころクリ + つるはしモグ
3. きらコウモリ導入
4. ゴロゴーレム + 3種混成
5. 全4種 → 琥珀ガメ
